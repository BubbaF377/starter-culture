StarterCulture is the marketing website for StarterCulture, a small AI-native software development studio. If you're a visitor landing on starterculturestudio.com — a prospective client, a fellow developer, or just someone curious about the studio — this is your guide to what's on the page and how to use it. There's nothing to install or configure here: StarterCulture is a single-page site you read and scroll through, and this manual walks through each part of it and what you'll find there.

## Getting Around the Site
<!-- requirements: #1 -->

StarterCulture lives entirely on one scrolling page — there's no separate "About" page or "Products" page to click through to. Everything you need is stacked in order as you scroll down from the top: a header/nav bar, a hero introduction, a section about the studio, a section listing the studio's products, a contact section, and a footer.

If the header includes in-page links (for example, jumping straight to Products or Contact), clicking one will scroll you down to that section rather than loading a new page. This makes it easy to skim the whole site quickly or jump straight to the part you care about, like the product list or contact details.

## Browsing Products
<!-- requirements: #6 -->

The products section is where StarterCulture lists what the studio has built. Each product is shown with a status pill telling you exactly how far along it is — currently either "In development" or "Beta" — so you can tell at a glance what's ready to use versus what's still being built.

Right now the section features **Devlore**, marked with a "Beta" pill, along with a short description: "Devlore is an agentic knowledge base that automatically documents every push across your project repos, with human review only at release time." If you want to try it or see the package directly, click through on Devlore's entry — it links out to its npm package at `https://www.npmjs.com/package/@starterculture/devlore`.

As the studio ships more products, they'll appear in this same list, each with its own status pill and description, so it's worth checking back here over time to see what's new.
